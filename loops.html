2. Sum of First N Numbers

Using do...while loop
Total Sum
15
1 + 2 + 3 + 4 + 5
View JS Do...While Loop 
let sum = 0;
let i = 1;
do {
  sum += i;
  i++;
} while (i <= n);

3. Average of First N Numbers

Using for loop
Average Value
3.00
15 ÷ 5 = 3.00
View JS For Loop 
let total = 0;
for (let i = 1; i <= n; i++) {
  total += i;
}
const average = total / n;
